# ConFusion — лабораторная работа № 2

## Состав проекта

- `aboutus.html` — готовая адаптивная страница «О нас».
- `css/styles.css` — собственные стили страницы.
- `materials/` — исходное задание и исходная HTML-вёрстка.

## Запуск

Откройте `aboutus.html` в браузере. Bootstrap 4, jQuery и Popper.js подключаются по CDN, поэтому для корректной загрузки библиотек требуется подключение к Интернету.

## Выполненные требования

1. Подключены Bootstrap CSS, собственные стили и JavaScript-компоненты Bootstrap.
2. Использованы классы `container`, `row`, `col-12`, `col-sm-6` и другие адаптивные классы сетки.
3. Заголовок «О нас» занимает всю ширину строки.
4. Блок «Наша история» занимает половину строки на экранах от размера `sm`.
5. Раздел «Руководство» занимает всю ширину строки.
6. Для подробных описаний руководства применены `d-none d-sm-block`.

## Публикация на GitHub

Загрузите папку `ConFusion_Lab2` в свой репозиторий. Если у вас уже есть `index.html` и другие файлы исходного проекта, добавьте `aboutus.html` и папку `css` в корень этого проекта.
